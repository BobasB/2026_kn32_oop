### Практикуємось з вставкою коду в README.md

1. Вставляємо код посередині тексту `Code Block` далі йде текст.
1. Вставка багатострічкового коду:
    ```
    Code block line 1
    Code block line 2
    ```
1. Вставка багатострічкового коду з підсвіткою синтаксису:
    ```java
    public class HelloWorld {
        public static void main(String[] args) {
            System.out.println("Hello, World!");
        }
    }
