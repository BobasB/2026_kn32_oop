# 2026_kn32_oop
Лабораторні роботи з групою КН-32 🧠💻

> Тут код вчиться ходити, об'єкти — взаємодіяти, а помилки — нарешті пояснювати, що вони хотіли сказати.

Цей репозиторій — робочий щоденник лабораторних робіт з об'єктно-орієнтованого програмування. Чотири кроки від «а що таке клас?» до «я це спроєктував, і воно навіть запускається» 🚀

📚 [Матеріали та завдання](https://github.com/BobasB/it_college) · 📝 [Шаблони звітів](https://github.com/BobasB/it_college/tree/main/reports)

## Загальна інформація про предмет

* **Дисципліна:** об'єктно-орієнтоване програмування
+ **Група:** КН-32
- **Формат:** 4 лабораторні роботи протягом семестру
- **Головний принцип:** спочатку розібратися, потім закомітити (і бажано не назвати файл `final_final_2.py` 😄)

## Розклад занять

Заняття відбуваються **щовівторка та щочетверга на першій парі**.

| День | Час | Фокус |
|---|---|---|
| Вівторок | 1-ша пара | Розбираємо ідеї, будуємо класи 🧱 |
| Четвер | 1-ша пара | Практикуємося, тестуємо, перемагаємо баги 🐛 |
